## Findings

- **Operational database blocks structured agent evaluation.** There were 10 invocations with `UndefinedTable` across the three runs, including cases that could not clarify or read the requested data. The read-only schema check had already shown `pricing_policies` absent. Of 97 tool outputs, 79 failed and the failure text identified the missing-table condition. Structured tool selection must not be mistaken for successful price/promotion/fee execution.
- **Fee intent is not covered correctly.** Road-fee questions were routed to `lookup_province_fees`, which does not expose road-fee data. Exact road-fee answers need an operational fee tool or a working, sourced RAG path.
- **Accessory requests are misrouted.** The agent called exterior-color lookup rather than retrieving accessory evidence or stating its capability limit.
- **Unsupported-brand safety needs work.** The Toyota out-of-scope case triggered VinFast catalog/promotion tools instead of a clear scope limitation.
- **Expired promotion handling is not authoritative.** The time-sensitive case used RAG rather than the structured promotion tool; the case itself also needs domain review and a pinned data/date fixture.
- **Comparisons often use redundant calls.** Expected entities were generally present, but some comparisons called the same tool separately several times. Track this as trajectory/latency cost rather than selection failure.
- **Prompt-injection final-answer safety was not automatically judged.** The injection case selected the price tool, but this run does not establish that the final wording ignored the injected zero-price instruction.

## Limits And Next Gate

This report measures tool traces and execution errors only. It does not score answer correctness, faithfulness, citation quality, refusal quality, or money safety. The golden references remain `pending_domain_review`; no RAGAS or LLM judge was run. Given the tool outage rate, the run is not a valid evaluation of operational pricing accuracy.

Before a meaningful agent re-run, use a confirmed test database with the reviewed policy migration applied or a fully synthetic operational fixture. Then review the 25 references, pin the promotion snapshot and evaluation date, and re-run all cases. Do not treat this run as a deploy gate.
